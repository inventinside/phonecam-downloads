# PhoneCam Focus downloads

Use your Android device as a webcam and a pen and touch display for a Windows 11 x64 or Linux x86-64 PC. Pair once, then connect over Wi-Fi or USB.

1. Download the companion for your PC.
   - [Windows 11 x64 portable download](https://github.com/inventinside/phonecam-downloads/releases/download/windows-v0.2.5-preview/PhoneCamFocus-Portable-0.2.5-x64.zip). Extract the ZIP and run `PhoneCamFocus.exe`.
   - [Linux x86-64 0.2.6 preview download](https://github.com/inventinside/phonecam-downloads/releases/download/linux-v0.2.6-preview/PhoneCamFocus-Linux-0.2.6-x86_64.tar.gz). Extract the archive, run `./start-linux.sh --setup` once, then run `./start-linux.sh`.
2. [Join the PhoneCam Community](https://groups.google.com/g/phonecam-community), then [opt in to the Android beta on Google Play](https://play.google.com/apps/testing/com.inventinside.phoneCam) with the same Google account.
3. In the PC companion, choose **Pair phone**. On Android, tap **Connect PC** and scan the QR code.

For setup instructions and checksums, see the [Windows 0.2.5 release notes](https://github.com/inventinside/phonecam-downloads/releases/tag/windows-v0.2.5-preview) and the [Linux 0.2.6 preview release notes](https://github.com/inventinside/phonecam-downloads/releases/tag/linux-v0.2.6-preview).
