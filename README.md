# PhoneCam Focus downloads

PhoneCam Focus lets an Android device serve as a Windows webcam and a pen and touch display over your local network. The PC companion requires Windows 11 x64.

Windows companion downloads will be attached to [versioned releases](https://github.com/inventinside/phonecam-downloads/releases). Each release will identify the compatible Android app and include file checksums.
