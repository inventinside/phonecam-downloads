# PhoneCam Focus downloads

PhoneCam Focus lets an Android device serve as a Windows webcam and a pen and touch display over your local network. The PC companion requires Windows 11 x64.

The [Windows 11 x64 preview](https://github.com/inventinside/phonecam-downloads/releases/tag/windows-v0.2.1-preview) includes an installer and a portable ZIP. The release page has pairing instructions and file checksums. You need access to the PhoneCam Android test on Google Play to use the Windows companion.
