# PhoneCam Focus downloads

Use your Android device as a webcam and a pen and touch display for a Windows 11 x64 PC. Pair once, then connect over Wi-Fi or USB.

1. [Download the Windows portable companion](https://github.com/inventinside/phonecam-downloads/releases/download/windows-v0.2.5-preview/PhoneCamFocus-Portable-0.2.5-x64.zip). Extract the ZIP and run `PhoneCamFocus.exe`.
2. [Join the PhoneCam Community](https://groups.google.com/g/phonecam-community), then [opt in to the Android beta on Google Play](https://play.google.com/apps/testing/com.inventinside.phoneCam) with the same Google account.
3. In Windows, choose **Pair phone**. On Android, tap **Connect PC** and scan the QR code.

See the [Windows 0.2.5 release notes](https://github.com/inventinside/phonecam-downloads/releases/tag/windows-v0.2.5-preview) for webcam setup, checksums, and third-party sources.
